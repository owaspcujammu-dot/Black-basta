Brand images
============

Files placed in this folder replace the built-in drawings automatically
(no code change, no rebuild in development; rebuild the frontend for production).

  emblem.png  (or .svg / .webp / .jpg)   Logo: header, landing hero, login page.
                                         Square, at least 512x512. Transparent or white background.

  ship.png    (or .webp / .jpg)          Ship picture on the landing page.
                                         Landscape, at least 1200px wide.

Only use artwork you have the right to use. Official One Piece artwork
(for example the Straw Hat emblem or the Thousand Sunny) belongs to its
rights holders: use it only if your event has permission to.
